# Launch checklist

- Select a dedicated Supabase project and review migrations in staging.
- Implement authentication, family and organization invitations, moderation, and family stewardship verification.
- Implement private/unlisted storage authorization and signed URLs.
- Publish privacy, terms, memorial guidelines, copyright/takedown, retention, and preservation policies.
- Add real search with strict visibility filters, rate limits, upload validation, and audit trails.
- Test anonymous, family, organization, moderator, and administrator accounts.
- Test private/unlisted direct URLs, access revocation, succession, and disputed stewardship.
- Test accessibility, captions, reduced motion, and mobile layouts.
- Configure independent database and storage backups and verify restoration.
- Seed only researched, source-cited memorials with rights-cleared media and editorial approval.
